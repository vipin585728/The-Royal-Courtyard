# 🏨 The Royal Courtyard

A modern, elegant and fully responsive hotel website built using **HTML, CSS and JavaScript**.

## ✨ Features

* 🏨 Luxury hotel homepage
* 🛏️ Rooms & Suites section
* 📅 Booking availability form
* 🍽️ Restaurant & dining section
* 🏊 Hotel amenities
* 🖼️ Responsive image gallery
* 🎁 Special offers section
* ⭐ Guest testimonials
* 📞 Contact form
* 📱 Fully responsive design
* 🎨 Modern luxury UI
* ⚡ Smooth scrolling and animations

## 🛠️ Technologies

* HTML5
* CSS3
* JavaScript
* Google Fonts
* Responsive Web Design

## 🚀 Getting Started

1. Clone this repository.
2. Open `index.html` in your browser.
3. Customize the hotel name, images, prices and contact details as needed.

## 📁 Project Structure

```text
the-royal-courtyard-hotel/
│
└── index.html
```

## 📸 Website

The website is designed for a luxury hotel and can be customized with real hotel images, booking systems, WhatsApp integration and payment functionality.
